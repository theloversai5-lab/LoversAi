# Copy

This product is for families and planners, not engineers. Write like you are talking to a child who is careful with words.

## Line length

**A line is 4 or 5 words. Not more.**

If a thought needs more words, break it:

```
Close more weddings
with less work
```

Not:

```
Execute and close more weddings easier
```

## Shortest is better

Cut every extra word. Prefer verbs people know: pick, show, send, hire, find, start.

## Voice

- Warm, calm, sure.
- No slang, no jokes that need insider knowledge.
- No “AI”, “pipeline”, “dashboard”, “ecosystem” on the glass if a plain word exists.
- Buttons: `Continue`, `Start`, `Hire`, `Plan myself` — not `Submit`, `Proceed`, `Execute`.

## Unveiling questions

One question. One helper line (also 4–5 words). Then Continue.

Good:

```
What is your name?
Who we talk to.
```

```
Which city?
Where you mostly work.
```

```
Hiring or looking?
This sets your home.
```

Bad: paragraphs, two questions, legal tone.
